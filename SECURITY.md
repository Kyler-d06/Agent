# Security policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed
credential. Contact the repository owner privately with a concise description,
reproduction steps, and the potential impact. Acknowledgement and next steps
will be provided as soon as practical.

Never include real credentials, private runtime data, or personal information in
an issue, pull request, test fixture, or log.
